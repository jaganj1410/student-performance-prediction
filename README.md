# Student Performance Prediction

A beginner-level machine learning project that predicts whether a student is likely to pass or fail based on academic and attendance-related factors.

## Objective

The objective of this project is to understand the basic workflow of a machine learning classification problem, from preparing input data to training a model and generating predictions.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Logistic Regression

## Input Features

The model uses the following student-related features:

- Study Hours
- Attendance
- Previous Marks

## Methodology

1. Created a dataset containing student academic information.
2. Prepared the input features and target labels.
3. Split the data into training and testing sets.
4. Trained a Logistic Regression classification model.
5. Generated pass/fail predictions for new student data.
6. Evaluated the model using accuracy.

## Model

The project uses **Logistic Regression** for binary classification of student outcomes.

## Learning Outcome

Through this project, I learned the basic process of building a machine learning classification model using Python, including data preparation, train-test splitting, model training, prediction, and evaluation.
